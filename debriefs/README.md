# 📁 Debriefing-Dateien (Sessions & Reports)

Dieser Ordner dient zur lokalen Speicherung deiner Sprung-Debriefings:
- **`*_debrief.json`**: Gespeicherte Debriefing-Sessions mit allen Punkten, Zeiten, Notizen und Videopfade.
- **`*_report.md`**: Exportierte Debrief-Berichte.

> [!NOTE]
> Der Inhalt dieses Ordners (mit Ausnahme dieser `README.md`) wird per `.gitignore` vom Git-Repository ausgeschlossen, damit persönliche Trainingsdaten und Notizen nicht unbeabsichtigt versioniert oder übertragen werden.
