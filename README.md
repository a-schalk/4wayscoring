# 🪂 4-Way FS – 3D Formationen & Blöcke

Interaktiver WebGL/Three.js 3D-Viewer und Editor für FAI 4-Way Formation Skydiving Formationen und Blöcke.

🌐 **Live GitHub Pages Web App:** [https://a-schalk.github.io/4wayscoring/](https://a-schalk.github.io/4wayscoring/)

### Features
- 3D-Visualisierung aller FAI 4-Way Formationen (Randoms A–Q und Blöcke 1–22)
- Interaktive Animationen mit Play/Pause, Zeit-Scrubbing und Geschwindigkeitsregler
- Multi-Kamera-Perspektiven (Draufsicht/Top, Schräg/Perspektive, Seitlich)
- SDC Rhythm XP Continuity Booklet Referenzbilder als Overlay
- Slot-Markierungen: Point (Rot), Outside Center (Grün), Inside Center (Blau), Tail (Gelb)
- Integrierter visueller 3D-Editor für Posen und Pieces
